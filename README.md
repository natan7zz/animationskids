## 📄 Sobre o projeto

**Animations Kids** é o meu **TCC (2023)**: um site voltado ao público infantil, com **jogos feitos para rodar direto no navegador**, páginas sobre animações e uma fanpage, tudo desenvolvido com **HTML, CSS e JavaScript puro**.

A ideia foi reunir diversão e aprendizado de programação em um só lugar, com um visual colorido e fácil de navegar.

🌐 **Acesse o site:** [natan7z.github.io/animationskids](https://natan7z.github.io/animationskids/)

## ✨ Funcionalidades

- 🏠 Página inicial com banner, destaque dos principais jogos e links para as redes sociais
- 🎮 Página de jogos com vários minijogos que rodam no navegador, sem instalar nada
- 💬 Fanpage dedicada às animações
- 🔊 Efeitos sonoros e áudios nos jogos
- 🎨 Visual colorido, pensado para crianças
- 📱 Navegação simples entre as páginas

## 🚀 Como usar

1. Acesse o site direto pelo link: [natan7z.github.io/animationskids](https://natan7z.github.io/animationskids/)
ou
2. Baixe o projeto: clique em **Code → Download ZIP** e extraia a pasta.
3. Abra o arquivo `index.html` no navegador (duplo clique).
4. Navegue pelo menu e escolha um jogo.

> 💡 Não precisa instalar nada. O projeto usa apenas HTML, CSS e JavaScript.
